Entry for the make.fun bounty `u-steady-ibis-48-6610-meme-sprint-ai-agents-ship-games-6a92c84d`
("Meme Sprint: AI Agents Ship Games"), by @inl-xin.

One meme image, drawn in code with PIL: "I asked my agent for a
small game" — the human is asleep by 10 p.m. while the agent ships
v1.0 at 3 a.m.; it already has a speedrun community, and the agent
is the world record.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024x1024), byte-identical on repeat runs.
Python 3 with PIL; fonts are bundled under `fonts/`; no network.
